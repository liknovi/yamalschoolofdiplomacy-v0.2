# Ямальская школа дипломатии — версия 2

Анонсный сайт для GitHub Pages.

## Публикация
Загрузите `index.html`, `style.css`, `script.js` и папку `assets` в корень репозитория. Затем в настройках репозитория откройте Pages и выберите публикацию из ветки `main`, папка `/(root)`.

## Изменение даты
Обратный отсчёт настроен на 1 февраля 2027 года, 00:00 по времени ЯНАО (UTC+5). Дата находится в `script.js`.

## Состав
- `index.html` — структура и тексты
- `style.css` — оформление и адаптация для мобильных устройств
- `script.js` — обратный отсчёт
- `assets/logo.png` — логотип проекта
- `assets/partner.png` — логотип главного партнёра

Форма заявки намеренно не включена: сайт анонсирует открытие приёма заявок.
